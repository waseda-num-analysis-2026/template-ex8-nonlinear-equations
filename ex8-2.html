Exercise 8.2 — Simultaneous Root-Finding by the DK Method

Numerical Analysis 2026 — Lecture 8

Problem

Implement the Durand–Kerner (DK) method (also known as Weierstrass’s method) for finding all roots of a polynomial simultaneously, and reproduce the experimental results from Section 5.2 of the shared handout.

The DK update for a monic degree-\(n\) polynomial \(p(z) = \prod_{j=1}^n (z - z_j)\) is

\[ z_i^{(k+1)} = z_i^{(k)} - \frac{p(z_i^{(k)})}{\displaystyle\prod_{j \neq i}(z_i^{(k)} - z_j^{(k)})}, \qquad i = 1, \dots, n. \]

Required tasks:

  • Implement the DK method
  • Use the same polynomial examples as handout Section 5.2
  • Use the same simple circle-based initial values as the handout
  • Show convergence behavior via plots
  • Report final approximations and residuals in a table

Optional extension (bonus):

Implement Aberth-type initial values and compare them with the simple circle-based initial values. See Aberth (1973), Math. Comp. 27(122), 339–344, Section 4.

AI is permitted. AI is recommended for plotting.

1. Implementation

1.1 DK iteration

import numpy as np
import matplotlib.pyplot as plt

def dk_method(coeffs, z0, max_iter=100, tol=1e-10):
    """
    Durand--Kerner (Weierstrass) method for simultaneous polynomial root-finding.

    Parameters
    ----------
    coeffs : array-like
        Coefficients of the monic polynomial in descending order, i.e.
        p(z) = z^n + coeffs[0]*z^(n-1) + ... + coeffs[n-1].
        Pass the coefficients of the non-leading terms only (length n).
    z0 : array-like of complex
        Initial approximations for all n roots (length n).
    max_iter : int
    tol : float
        Stopping criterion: max_i |p(z_i)| < tol.

    Returns
    -------
    z_history : list of 1-D complex arrays  (length = iterations + 1)
    res_history : list of floats            max_i |p(z_i)|
    converged : bool
    """
    # Build coefficient array for np.polyval:  [1, coeffs[0], ..., coeffs[n-1]]
    full_coeffs = np.concatenate([[1.0], coeffs])
    n = len(z0)
    z = np.array(z0, dtype=complex)
    z_history = [z.copy()]
    res_history = [np.max(np.abs(np.polyval(full_coeffs, z)))]

    for _ in range(max_iter):
        z_new = z.copy()
        for i in range(n):
            pz = np.polyval(full_coeffs, z[i])
            denom = np.prod(z[i] - np.delete(z, i))  # product over j != i
            # TODO: update z_new[i]
            z_new[i] = None  # replace with correct DK step
        z = z_new
        res = np.max(np.abs(np.polyval(full_coeffs, z)))
        z_history.append(z.copy())
        res_history.append(res)
        if res < tol:
            return z_history, res_history, True

    return z_history, res_history, False
