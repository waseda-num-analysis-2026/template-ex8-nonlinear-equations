Exercise 8.1 — Multi-Dimensional Newton’s Method

Numerical Analysis 2026 — Lecture 8

Problem

Implement Newton’s method for a 2D or higher-dimensional system of nonlinear equations

\[ F(\mathbf{x}) = \mathbf{0}, \qquad F : \mathbb{R}^n \to \mathbb{R}^n, \]

where the Jacobian \(J_F(\mathbf{x})\) is used at each step:

\[ \mathbf{x}^{(k+1)} = \mathbf{x}^{(k)} - J_F(\mathbf{x}^{(k)})^{-1} F(\mathbf{x}^{(k)}). \]

Tasks:

  • Implement the multi-dimensional Newton’s method
  • Solve a total of 3 examples
    • 2 examples: choose yourself (do not use the circle and parabola example from the handout)
    • 1 example: ask AI to choose (state which AI you used and what prompt you gave)
  • For each example, report the number of iterations and the final residual \(\|F(\mathbf{x}^{(k)})\|\)
  • Briefly discuss your observations (convergence speed, sensitivity to initial guess, etc.)

AI is permitted. AI is recommended for plotting and for selecting the AI-chosen example.

1. Implementation

Complete the Newton iteration. Solve the linear system \(J_F \Delta\mathbf{x} = -F\) at each step using np.linalg.solve instead of computing \(J_F^{-1}\) explicitly.

import numpy as np
import matplotlib.pyplot as plt

def newton_nd(F, J, x0, max_iter=50, tol=1e-10):
    """
    Multi-dimensional Newton's method.

    Parameters
    ----------
    F : callable  F(x) -> 1-D array of length n
    J : callable  J(x) -> 2-D array of shape (n, n)   (Jacobian of F)
    x0 : array-like  initial guess (length n)
    max_iter : int
    tol : float  stopping criterion  ||F(x)|| < tol

    Returns
    -------
    x_history : list of 1-D arrays  (length = number of steps taken + 1)
    res_history : list of floats    ||F(x^(k))||
    converged : bool
    """
    x = np.array(x0, dtype=float)
    x_history = [x.copy()]
    res_history = [np.linalg.norm(F(x))]

    for k in range(max_iter):
        Fx = F(x)
        Jx = J(x)
        # TODO: solve J(x) * delta = -F(x) for delta, then update x
        delta = None  # replace with np.linalg.solve(...)
        x = x + delta
        res = np.linalg.norm(F(x))
        x_history.append(x.copy())
        res_history.append(res)
        if res < tol:
            return x_history, res_history, True

    return x_history, res_history, False
